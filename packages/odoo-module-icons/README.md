# odoo-module-icons

Agent skill que diseña el `icon.png` de un módulo de Odoo para que se vea nativo en el menú de aplicaciones de Odoo 19, en tema claro y oscuro.

```bash
npx odoo-module-icons            # global: ~/.claude/skills/
npx odoo-module-icons --project  # proyecto: ./.claude/skills/
npx odoo-module-icons --dir <ruta>
```

También disponible vía [skills.sh](https://skills.sh/EmanuelAlv/odoo-skills): `npx skills add EmanuelAlv/odoo-skills`
